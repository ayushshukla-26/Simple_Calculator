# 🧮 Simple Python Calculator

A beginner-friendly, terminal-based calculator built using **Python only**. It performs basic mathematical operations through a simple menu-driven interface.

## 🚀 Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Handles invalid inputs
- Prevents division by zero
- Runs until the user chooses to exit

## 🛠️ Technologies Used
- Python

## ▶️ How to Run

1. Clone this repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder.

3. Run the program:
   ```bash
   python calculator.py
   ```
